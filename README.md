# humor-project

A minimal [Next.js](https://nextjs.org) app — App Router, TypeScript, one page.

**Live:** https://humor-project-orpin.vercel.app

## Develop

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000). Edit `app/page.tsx` and the page
hot-reloads.

## Deploy

Pushes to `main` deploy to production automatically via the Vercel GitHub
integration. Pull requests get their own preview deployment.
